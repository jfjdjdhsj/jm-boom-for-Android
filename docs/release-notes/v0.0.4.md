# v0.0.4

## 功能

- 无新增功能。

## 优化

- 条漫模式切章后先强制把滚动位置校正到目标页，再开始跟踪阅读进度，切章首屏更稳定。

## 修复

- 修复条漫（竖屏连续滚动）模式下，读到本章最后一页再点击“下一章”会跳到新章节最后一页的问题。
  切章时容器可能沿用上一章的滚动位置，图片陆续加载又改变了高度，观察器因此把末页上报成了新章节的当前页。
- 条漫模式首次定位完成前不再上报页码，并限制切章初始阶段单次页码跳变幅度，避免残留页码覆盖进度。

## 其他

- 版本号同步更新到 0.0.4（`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`）。
- 本版本仍由 GitHub Actions 构建分架构 APK，本地不执行 APK 构建。
