# v0.0.5

## 功能

- Android 支持应用内下载安装更新：检测到新版本后直接把 APK 下载到 App 私有目录，再调用系统安装器完成安装，不再跳转浏览器。
- 下载更新时显示实时进度百分比。
- 安装结束（成功或失败）后自动删除私有目录里的安装包；下一次启动还会再做一次兜底清理，不残留占用空间。

## 优化

- Android 检查更新改为先读取 Releases 页面重定向获取最新版本号，GitHub API 仅用于补充更新说明。
- 检查更新结果在 App 内缓存 6 小时，短时间内重复点击不再重复发起网络请求。
- 检查更新遇到限流或断网时静默降级为“已是最新”，不再弹出报错，同时保留手动下载页入口。

## 修复

- 修复检查更新失败并提示 `HTTP status client error (403 rate limit exceeded)` 的问题。
  原因是 Android 端直接调用 GitHub REST API，未认证请求按 IP 限流（60 次/小时），移动网络共用出口 IP 时很容易触发。

## 其他

- Android 端新增 `UpdateInstaller` 插件（由构建脚本 `scripts/configure-android-updater.sh` 注入），用于提供私有目录与系统安装能力。
- 版本号同步更新到 0.0.5（`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`）。
- 本版本仍由 GitHub Actions 构建分架构 APK，本地不执行 APK 构建。
