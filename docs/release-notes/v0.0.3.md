# v0.0.3

## 功能

- 无新增功能。

## 优化

- 切换章节时阅读器整体重建，避免沿用上一章的阅读状态，切章后的首次加载更快更干净。
- 条漫模式在程序化滚动（切章定位、翻页定位）期间不再上报中途经过的页码，阅读进度更准确。

## 修复

- 修复阅读时点击“下一章”/“上一章”后没有回到新章节第一页，而是跳到末页或残留的旧页码（例如 100 多页）的问题。
- 修复切章瞬间页码重置与越界收敛逻辑互相覆盖，导致页码被改写成新章节最后一页的问题。

## 其他

- 版本号同步更新到 0.0.3（`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`）。
- 本版本仍由 GitHub Actions 构建分架构 APK，本地不执行 APK 构建。
